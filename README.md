# 🗺️ CODIMAP
**카카오 지도 기반 코디 사진 공유 SNS**

CODIMAP은 사용자가 특정 지역에서 촬영한 코디 사진을 공유하고, 지도를 통해 다양한 지역의 패션 트렌드를 탐색할 수 있는 웹 서비스입니다. 지역과 계절을 기반으로 코디를 필터링하여 원하는 스타일을 쉽게 찾을 수 있습니다.

---

## 🛠️ 사용 기술 스택

**Backend**
- Node.js
- Express
- MySQL
- dotenv (환경변수 관리)

**Frontend**
- HTML, CSS, JavaScript
- 카카오 지도 API
- 카카오 주소 검색 API

**협업 & 배포**
- GitHub
- GCP (VM 인스턴스, Cloud DB)
- Notion (문서화 및 일정 관리)

## ⚙️ 설치 및 실행 방법 (로컬 환경 기준)

**1. 레포지토리 클론**
```
git clone https://github.com/lsy004444/codimap.git
cd codimap
```

**2. 패키지 설치**
```
npm install
```

**3. 환경변수 설정**
`.env` 파일을 생성하고 아래 내용을 입력합니다.
```
DB_HOST=your_db_host
DB_USER=your_db_user
DB_PW=your_db_password
DB_PORT=3306
DB_NAME=codimap_db
```

**4. 서버 실행**
```
node main.js
```

**5. 브라우저 접속** !!수정필요
```
http://
```
또는 VM 배포 시 `http://<VM 외부 IP>/map` 으로 접속

## 🧩 주요 기능

### 🗺️ 지도 메인 화면
- 카카오 지도 기반 메인 화면 렌더링
- 지역 검색 시 해당 위치로 지도 이동 및 마커 표시
- 계절별 (봄/여름/가을/겨울) 코디 필터링
- 마커 클릭 시 해당 지역 코디 피드 표시

### 📸 게시물 피드
- 지역 + 계절 기반 게시물 그리드 표시
- 무한 스크롤
- 게시물 상세보기 (이미지 슬라이더, 쇼핑 링크, 댓글)
- 스크랩 / 신고 기능

### 📝 게시물 등록
- 사진 업로드 및 EXIF 메타데이터 자동 추출 (위치, 날짜)
- 위치 정보 없을 시 카카오 주소 검색으로 직접 입력
- 쇼핑몰 링크 추가

### 👤 회원 기능
- 회원가입 / 로그인 / 비밀번호 찾기
- 마이페이지 (스크랩, 팔로잉/팔로워, 내 게시물, 내 댓글)
- 프로필 수정
